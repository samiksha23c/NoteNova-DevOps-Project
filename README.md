# NoteNova – Smart Study Material Analyzer

A student-focused web application for studying notes, summaries, keywords and quizzes.

## Current version

Version 0.1: Flask homepage and responsive landing page. Analysis tools will be added in subsequent commits.

## Tech stack

- Python and Flask
- HTML and CSS

## Run locally

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000.
